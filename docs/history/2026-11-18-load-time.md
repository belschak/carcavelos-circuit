# Load time P8: the campus world as its own cached file (18 Nov 2026)

The measurement behind decision 2026-11-18 in [../decisions.md](../decisions.md) (pull request #159). Since that change the Web build is two downloads: the game (code, engine, menus) and the campus world `Build/world-<content hash>.bundle`, loaded by `RaceFlow/WorldStream.cs`. How it works: [../architecture.md](../architecture.md#what-happens-when-you-open-the-link).

## How it was measured

- Two builds from GitHub Actions: `main` before the change (world inside the `.data`) and the P8 build (world as its own file).
- Served from a local server that behaves like GitHub Pages (gzip) and limits the line to 4 Mbit/s with 60 ms round trip. Throttling inside the browser's developer tools gave unreliable speeds, so the server did the shaping.
- "Play" = the "Click to play" screen appears; the times below are that moment, in seconds.

## Sizes over the wire (gzip)

| Part | Size |
|---|---|
| Game: `.wasm` 9.4 MB + `.data` 15.0 MB + loader script 0.1 MB | about 24.5 MB |
| Campus world, desktop (DXT textures) | about 25.8 MB |
| Campus world, phones (ETC2 textures) | about 31.5 MB |
| Total on a desktop | about 50 MB (the same as before the change) |

Later builds differ by a few MB (new textures, sounds); the split stays about half and half.

## Results at 4 Mbit/s

| Visit | `main` before | P8 | Why |
|---|---|---|---|
| First visit (nothing cached) | 114.7 s | 120.7 s | Same bytes, so about the same time |
| Second visit, same build | 0.7 s | 1.7 s | Everything comes from the browser cache |
| After a deploy that changed only code | 113.5 s | 55.7 s | The world file keeps its name, so it stays cached; only the game (about 24 MB) is downloaded again |

Every run had 0 console errors. Blocking the world file on purpose showed "The track did not download" after two attempts, and the game did not fall back to the test track.

## What this does not fix

A first visit on a slow line still takes about 2 minutes: a 50 MB game cannot load in seconds at 4 Mbit/s. A menu that works before the world has arrived would need the race to be set up without the track, a bigger change than the deadline allowed ([../limits-and-next-steps.md](../limits-and-next-steps.md)).
