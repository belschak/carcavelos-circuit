# Decision log

Newest on top. One line per decision: date, decision, why. Agents: never contradict a decision here without asking the team.

- 2026-11-08: **Audio mastering + Web loops (P4, Role 4).** Every clip: Normalize off, Decompress On Load + Preload (music too), Web override AAC (quality 1.0 effects, 0.7 music), set by `RaceFlow/Editor/AudioImportSetup`. Loudness lives in the files: `tools/audio-synth/process_wavs.py` re-levels by RMS (targets in `audio-polish-plan`), peaks max -1 dBFS, loops get 2048 samples of leading silence + a `smpl` loop chunk. Why: Unity re-encodes every clip to AAC for the Web, and the Windows AAC encoder alters the first 1024 samples (clicks at the loop point); WAV is kept as source because only WAV carries loop points. Replaces the reasoning "WAV only (no AAC loop gaps on Web)" in the sound-set line below (WAV alone does not prevent gaps).
- 2026-11-08: **No AudioMixer; mix and ducking in script (P4).** Unity's Web build only supports mixer group volume (no Duck Volume, compressor, limiter, filters) and there is no public editor API to create a mixer asset from code (only reflection on an internal class, which our style rules forbid). `RaceFlow/RaceMusic` fades per-phase levels in dB (`Audio/LevelFade`, `Audio/DuckEnvelope`) and sets the kart mix via `KartAudio.SetMixLevels`. Same behaviour in Editor and browser, unit tested.
- 2026-11-08: **`RaceFlow` references `Audio` (P4).** Needed for `RaceMusic` (mix maths, `KartAudio.SetMixLevels`). One direction only: `Audio` still references only `Shared`, so kart sounds keep reading nothing but `IKartState`. `RaceMusic` replaces `Audio/MusicPlayer` in `Main.unity` (the old file can be deleted in the Editor).
