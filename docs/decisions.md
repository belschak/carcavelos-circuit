- 2026-11-08: **Audio mastering + Web loops (P4, Role 4).** Every clip: Normalize off, Decompress On Load + Preload (music too), Web override AAC (quality 1.0 effects, 0.7 music), set by `RaceFlow/Editor/AudioImportSetup`.
