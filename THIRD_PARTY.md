Allowed without asking: Kenney assets (CC0, https://kenney.nl). Everything else: team OK first (`AGENTS.md`).

Audio from ElevenLabs: note the plan used per file. Free plan = non-commercial only, credit "Sound effects: elevenlabs.io" (music: "Eleven Music") in the game credits and on the itch.io page. No donations or "pay what you want" on itch with free-plan audio.

Own work (not third party, listed so nobody wonders): the HUD plate pictures in `Assets/_Project/RaceFlow/UI/Art/` are drawn by our own code (`UI/PlateArt.cs`, `Editor/HudArtBuilder.cs`, task R15), CC0 like the rest. Also the other 18 files in `Assets/_Project/Audio/Clips/` (`sfx_*` incl. `sfx_hint_warning` and `sfx_shift_pop`, `ui_click`, `amb_wind_loop`, `loop_engine`, `loop_drift`, `music_campus_loop`, `music_results_loop`) are synthesised by our own script `tools/audio-synth/synth_sfx.py` (pure Python, no samples). Released as CC0 by the team. Same for the item-box roll tick `sfx_item_roll_tick` (task R7, 2026-11-10). The atrium piano's chords and crash (task T10, 2026-11-11) are no files at all: `Assets/_Project/Track/Piano/PianoTone.cs` makes them in code at game start (own work, CC0).

Own work too: all four karts (Nova Classic, Beach Buggy, Orbit, Street GT: `Visuals/Kart/Models/Kart_*.fbx`), their far versions (`Kart_*_Far.fbx`, `KartLOD_*` palettes, made by `tools/kart_lod/make_kart_lod.py`) and all tyre sets (`Tyre_*.fbx`, `TyreFar_*`) are built by Luc's own Blender scripts (`Art/Tools/build_formula.py`, `themes.py`, `wheel.py`, `build_tyres.py`), with no third-party mesh (Kenney's kart was used only up to v07 and is gone). The driver portraits (`RaceFlow/UI/Resources/DriverPortraits/`) are renders of these models by our own code (`Visuals/Editor/DriverPortraitBuilder.cs`); the loader key art is captured from our own game (`tools/ui_art/make_keyart.py`). CC0 like the rest.

All WAVs in the table above and the own files are mastered by our own `tools/audio-synth/process_wavs.py` (loudness level, loop padding, loop points; 2026-11-08, P4). That changes only level and adds silence, not the content, so the licences above are unchanged.
